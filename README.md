# OneScreen LATAM — estudio de video

Código, reglas y herramientas para producir los videos de OneScreen (HyperFrames).

1. Lee `CLAUDE.md` y luego `estudio-video/CLAUDE.md`.
2. Código por línea de video en `videos/`; la voz sale de `videos/onescreen-inta/voz_exp_d.py`.
3. Estilo y motion: `estilo-onescreen/`. Color S-Log3: `grade/`.
4. Storyboard, plantillas de motion y registro: `estudio-video/`.
5. Las claves son variables de entorno; los planos y renders no están en el repo.
